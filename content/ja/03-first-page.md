# ブラウザーで最初のページを見る

Rust のコードを読む前に、Senu を起動してブラウザーでそのページを開きます。いま読んでいるのと同じサイトが、あなたのコンピューターから配信されます。

## Senu を起動する

使うコマンドは `cargo run --quiet -- site` です。`cargo run` は、まずプログラムを**ビルド**し (Rust のソースファイルを、コンピューターが実行できるプログラムに変換すること)、それから**実行**します。`--quiet` は Cargo の進み具合の表示を隠します。`--` より後ろは Senu 自身に渡され、`site` はこの記事を配信するよう Senu に指示します。ターミナルで、`senu` フォルダーの中にいる状態で、これを入力して Enter キーを押してください。

```sh check=site server
cargo run --quiet -- site
```

最初のビルドでは Senu と、Senu が使うものすべてをコンパイルするので、数分のあいだ何も表示されないことがあります。そのまま待ってください。準備ができると、Senu は 1 行だけ表示します。

```text check=site
senu: listening on http://127.0.0.1:3000
```

プロンプトは戻ってきません。Senu はいま**サーバー**、つまり動き続けてリクエストに答えるプログラムになっているからです。このターミナルは開いたままにしておいてください。

## ページを開く

ブラウザーに切り替え、アドレスバーに **http://127.0.0.1:3000/ja/** と入力して Enter キーを押してください。章の一覧が載った、この講座の最初のページが表示されるはずです。

アドレスは三つの部分からできています。`http://` はブラウザーがサーバーと話す方法です。`127.0.0.1` は「このコンピューター」を表す**ローカルアドレス**で、インターネット上のほかの人は開けません。`3000` は**ポート**で、コンピューターの中で動いているどのプログラムにリクエストを渡すかを示す番号です。Senu が動いているあいだ、これらのページはあなただけのものです。

## 止めて、もう一度起動する

ターミナルに戻って Ctrl+C を押してください。Senu が止まり、プロンプトが戻ります。ブラウザーでページを再読み込みすると、もうそのアドレスに答えるものがないので、接続できないと表示されます。

同じコマンドで Senu をもう一度起動してください。前回のビルドから何も変わっていないので、今度は数秒で起動します。

```sh check=site-again server
cargo run --quiet -- site
```

```text check=site-again
senu: listening on http://127.0.0.1:3000
```

ブラウザーでページを再読み込みすると、元に戻ります。

## 二つ目のターミナルから尋ねる

サーバーにページを頼めるのはブラウザーだけではありません。Senu を一つ目のターミナルで動かしたまま、**二つ目のターミナル** (新しいウィンドウか、同じウィンドウの新しいタブ) を開き、`cd ~/senu` と入力してください。次のコマンドは二つのプログラムを使います。`curl` はページを取ってきて、その HTML (ブラウザーがページを描くもとになるテキスト) を表示します。`-s` は curl の進み具合の表示を隠します。`|` 記号はその出力を `grep` に渡し、`grep` はページの見出しを囲むタグ `<h1>` を含む行だけを表示します。次を実行してください。

```sh check=title
curl -s http://127.0.0.1:3000/ja/ | grep "<h1>"
```

スタートページの見出しが表示されます。

```text check=title
<h1>Rust で小さなノートサイトを作る</h1>
```

この講座では、各手順の結果をこの二つ目のターミナルで文字として確かめます。いつでも代わりにブラウザーで同じページを見てかまいません。

## 演習

ページ上部にある、英語に切り替えるリンクを見つけてたどってください。英語の最初のページのアドレスは何でしょう。どうやって戻りますか。

**解答.** リンクは English と書かれていて、http://127.0.0.1:3000/ に移ります。英語のページの同じ場所にある 日本語 というリンクで戻れます。両方の言語にある記事は、どれもそこから翻訳にリンクしています。

## うまくいかないとき

- **「could not find `Cargo.toml`」**: ターミナルが `senu` フォルダーにいません。`pwd` を実行してから `cd ~/senu` を実行してください。
- **「senu: cannot listen on 127.0.0.1:3000: address in use」**: Senu かほかのプログラムがポート 3000 を使っています。Senu が動いているターミナルを探して Ctrl+C を押してください。ほかのプログラムが使っている場合は、別のポートで起動します。コマンドの前に `NAME=value` と書くと、そのコマンドのときだけ設定 `NAME` が決まります。`=` の前後に空白は入れません。`SENU_BIND` は Senu が使うアドレスとポートを決める設定です。`SENU_BIND=127.0.0.1:3001 cargo run --quiet -- site` を実行し、代わりに http://127.0.0.1:3001/ja/ を開いてください。
- **ブラウザーが接続できない**: Senu が動いていません。Senu のターミナルを見て、プロンプトが戻っていたらもう一度起動してください。
- 最初のビルドで**「linker `cc` not found」**などのエラーが出た: インストールの章に戻ってください。
