# はじめに: これから作るもの

この講座では、Rust を一度も書いたことがない状態から始めて、実際に動いている Rust のプログラムを変更し、その変更が正しいことをテストで確かめるところまで進みます。別のフォルダーで練習用のおもちゃを作るのではありません。いま読んでいるこのページは Senu という小さなプログラムが表示しています。あなたはこの Senu を自分のコンピューターで動かし、自分のノートを書き足し、最後にその関数の一つを作り直します。

## 用意するもの

Linux、macOS、または WSL (Windows の中で動く Linux 環境です。次の章で用意します) が動くコンピューターと、そこにソフトウェアをインストールする権限、ダウンロードのためのインターネット接続が必要です。Rust の知識は要りません。JavaScript を少し見たことがあると役に立ちます。講座では、`let`、`const`、`function`、`if` と `else`、`import` と `export` といった JavaScript の言葉が出てくるたびに、Rust と比べて説明します。

全体でおよそ 2 時間を見込んでください。最初のビルドだけで数分かかることがあります。

## 三つのウィンドウ

この講座では三つのプログラムを行き来します。どの手順でも、どれを使うかを書いてあります。

- **ターミナル**は、コマンドを入力して Enter キーを押すウィンドウです。macOS では「ターミナル」アプリ、Linux では多くの場合「端末」や Terminal、WSL では Ubuntu のウィンドウです。
- **エディター**は、ファイルを開いて書き換え、保存するためのものです。プレーンテキストを扱えるエディターなら何でも使えます。Visual Studio Code がよく使われます。Word のようなワープロは書式を加えてしまうので使えません。
- **ブラウザー**は、Firefox、Chrome、Edge、Safari などで、Senu が配信するページを表示します。

## はじめてのターミナル操作

ターミナルがコマンドを受け付けられる状態になると、**プロンプト**が表示されます。`ada@laptop:~$` のように、`$` や `%` で終わる短い文字列であることが多いです。プロンプトはターミナルが表示するもので、自分で入力するものではありません。この講座では、コマンドが書かれた灰色の枠の中身が、プロンプトの後ろに入力する内容そのもので、その次の枠が返ってくるはずの表示です。

ターミナルを開いてください。`pwd` と入力して Enter キーを押すと、ターミナルがいま作業しているフォルダーが表示されます。これを**作業ディレクトリー**と呼びます。続けて `ls` と入力して Enter キーを押すと、そのフォルダーの中身が一覧表示されます。表示されるのは自分のコンピューターの内容なので、次の例とは違って見えます。

```text
pwd
/home/ada
ls
Desktop  Documents  Downloads
```

`cd` は作業ディレクトリーを移動します。`cd Documents` で Documents フォルダーに入り、`cd ..` で一つ上の階層に戻り、`cd` だけを入力するとホームフォルダーに戻ります。この講座のコマンドのほとんどは、次の章でダウンロードする `senu` フォルダーの中で実行します。コマンドが「見つからない」と言ってきたら、まず `pwd` で現在地を確かめてください。

## 演習

`ls` に表示されたフォルダーの一つに `cd` で入り、`pwd` で現在地を確かめてから、`cd ..` で戻ってください。

**解答.** `ls` に `Documents` が表示されたなら、`cd Documents` と入力し、次に `pwd` を実行すると答えの末尾が `/Documents` になります。最後に `cd ..` で戻ります。`cd` が「No such file or directory」と答えたら、つづりを確かめてください。Linux では、多くの場合 macOS でも、`documents` と `Documents` は別の名前として扱われます。

## うまくいかないとき

- **「command not found」**と表示される場合は、たいてい入力ミスです。つづりと、プロンプトの `$` まで入力していないかを確かめてください。
- **ターミナルが止まったように見え、プロンプトが出ない**場合は、コマンドがまだ動いています。Ctrl+C (Control キーを押しながら C) を押すと止まり、プロンプトが戻ります。この講座では Ctrl+C を何度も使います。
